# 日常收支记录

一个单文件的日常收支记录网页，按月记录收入与支出。

## 功能

- **月度记录**：收入、支出同屏显示；大项分类（下拉可选）+ 小项（自由文本）。
- **输入提速**：金额栏支持算式（输入 `=3000+500` 回车自动算成 3500）；支持从 Excel / 网页表格直接粘贴多行（列序：大项、小项、金额、备注）；回车跳到下一行、↑↓ 上下移动；小项输入框有历史高频补全。
- **月度汇总**：本月收入 / 支出 / 结余，以及计划余额、实际余额、余额偏差三属性（计划余额默认 = 上月实际余额 + 本月结余，可自定义并一键恢复默认）。
- **年度汇总**：12 个月卡片 + 大项收支占比（点月份卡片可跳转到该月明细）+ 月度趋势折线图（收入 / 支出 / 结余，点数据点跳到该月）。
- **年度对比**：历年收入 / 支出 / 结余对比。
- **分类管理**：收支大项可增删，支持重命名（改名会同步更新所有历史月份的大项）。
- **数据安全**：右上角「⋯ 数据」菜单可导出 JSON 备份、导出 CSV（Excel 可直接打开）、从 JSON 导入恢复、撤销上一步（Ctrl+Z）、删除本月数据（删除后内置历史数据不会把它复活）。
- **防止互覆**：云端保存前会先比对远端版本，若别处已更新会让你选择「合并 / 保留本地 / 使用云端 / 稍后处理」，不再无声覆盖。
- **移动端与深色模式**：窄屏自动变成卡片式录入，跟随系统深色模式。

## 使用

直接打开 `index.html`，或访问 GitHub Pages：

**https://romantic123fly.github.io/daily-ledger/**

## 数据存储

账目数据以 JSON 文件形式保存在本仓库的 `data/ledger.json`，网页通过 GitHub API 自动读写（不依赖第三方数据库）。本地数据存放在浏览器 `localStorage`，即使没配置 Token 也能正常记账。

首次访问时，点击页面右上角的「本地」状态标签，输入一个 GitHub Personal Access Token（需要 `repo` 权限）即可启用同步；Token 只保存在本浏览器。未配置 Token 时，数据仅保存在浏览器本地。

> 建议：改动较多数据前先用「⋯ 数据 → 导出 JSON 备份」留一份快照，误操作可以用 Ctrl+Z 或导入备份恢复。

## 开发自检

改完 `index.html` 后跑一遍冒烟测试（只用 Node，无需浏览器；用 DOM 桩执行页面内联脚本）：

```bash
node tests/smoke-test.js     # 首开渲染、算式、粘贴、撤销、基准合计回归（1,282,487 / 948,841）
node tests/migrate-test.js   # 老数据迁移、删除月份不复活、新用户首开持久化
```

两脚本都接受可选的 `index.html` 路径参数，默认取仓库根目录的 `index.html`；退出码非 0 表示有用例失败。
