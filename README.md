# 日常收支记录

一个单文件的日常收支记录网页，按月记录收入与支出。

## 功能

- **月度记录**：收入、支出同屏显示；大项分类（下拉可选）+ 小项（自由文本）。
- **月度汇总**：本月收入 / 支出 / 结余，以及计划余额、实际余额、余额偏差三属性（计划余额默认 = 上月实际余额 + 本月结余，可自定义并一键恢复默认）。
- **年度汇总**：12 个月卡片 + 大项收支占比（点月份卡片可跳转到该月明细）。
- **年度对比**：历年收入 / 支出 / 结余对比。
- **分类管理**：收支大项可增删编辑。

## 使用

直接打开 `index.html`，或访问 GitHub Pages：

**https://romantic123fly.github.io/daily-ledger/**

## 数据存储

账目数据以 JSON 文件形式保存在本仓库的 `data/ledger.json`，网页通过 GitHub API 自动读写（不依赖第三方数据库）。

首次访问时，点击页面右上角的「本地」状态标签，输入一个 GitHub Personal Access Token（需要 `repo` 权限）即可启用同步；Token 只保存在本浏览器。未配置 Token 时，数据仅保存在浏览器本地。
